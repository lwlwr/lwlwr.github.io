# 独立 Countdown 表达式评测工具

2026-10-23 新增，Python 3.10+，只依赖标准库。AI 辅助编写的独立补充，不能当作历史项目源码或本人独立手写能力的证明。它不包含训练、推理生成或企业材料。

```sh
python -m unittest discover -s tools -p 'test_*.py' -v
python tools/countdown_eval.py tools/examples/countdown.synthetic.jsonl
```

从仓库根目录运行。示例为人工合成的四条表达式，预期正确 2/4；该比例仅用于检查程序，不是模型 benchmark 成绩。

## 输入及规则

每行一个 JSON 对象：`id`（唯一非空字符串）、`numbers`（1–10 个正整数，每个不超过 1000000）、`target`（整数，绝对值不超过 10^12）、`expression`（已抽取的表达式字符串）。

- 必须恰好使用所有数字一次，重复数字按多重集合计数。
- 支持十进制整数字面量、括号和二元加减乘除；中间结果可为负数或分数。
- 不接受一元负号、浮点数、零字面量、幂、整除、变量或函数调用。
- 使用 AST 白名单和 Fraction，不执行输入代码；限制表达式长度与 AST 大小。
- 空表达式和非法表达式保留在分母内，除零判错。
- 缺字段、非法题目元数据、重复 ID 或空文件报错，不静默跳过。

输出包含输入文件 SHA256、逐题结果以及语法合法、数字使用合法、最终正确三项的分子、分母与比例。数字使用合法不保证表达式可计算，例如除零仍失败。

## 限制

工具只处理预先抽取的表达式，**不评测聊天模板或回答标签格式**。协议未必匹配历史 reward 或其他 Countdown 实现。AST 解析遵循 Python 运算语法，例如数字内下划线不在白名单内，前导零遵循 Python 语法约束。

示例文件不含完整任务清单，工具不能自动发现文件外被遗漏的任务。真实评测必须先按固定 manifest 对齐所有题目，对未返回的预测补空表达式，并报告覆盖率。当前是单候选正确率，不是 pass@k。

若用于历史结果复现，需先取回实际提示模板、抽取逻辑、奖励规则与固定划分，明确协议差异，再比较模型，不能直接套用历史数字。
