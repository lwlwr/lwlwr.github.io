个人工作

  • 在 Query 构造中加入用户画像、时间上下文、文件路径及 Skill / Cron 约束，组织 L1 / L2 / L3 难度任务。

评测方法与贡献边界

  • 区分工具执行成功、任务产物正确和最终回复一致。
  • 区分数据工程、权重更新与隔离集上的能力提升，分别验收。
  • 不将异步任务的重试与延迟观测收益归因于模型训练。

企业实习 · 训练诊断与导出华为 · 2026.06 – 2026.08

轻量 TTS · 对齐诊断、ONNX 与量化分析

面向端侧语音生成场景，在模型体积约束下开展 VITS-lite 训练评测、音质问题定位及推理导出工作。

个人工作

  • 搭建文本前端、MAS 对齐、Flow 与声码器的训练评测链路，组织 PESQ / STOI / MCD / RTF 评测。
  • 结合 MAS 路径、音素时长分布与 prior decoder 输出定位并修复对齐异常。
  • 通过外部噪声输入和固定随机种子，开展 PyTorch / ONNX 输出一致性验证。

工程验证

  • 开展 INT8 校准、验证和逐层敏感性分析，定位敏感算子。
  • 分别检查导出成功、固定输入数值一致、目标设备运行及质量性能验收。
  • 本页不将波形余弦相似度等同于主观音质，也不声称目标 NPU 已验收通过。
