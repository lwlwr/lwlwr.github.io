# 华为轻量 TTS：训练诊断与导出验证

## 历史工作范围

2026.06–2026.08，多模态算法实习。根据现有简历：
- 搭建 VITS-lite 训练评测链路，涉及文本前端、MAS、Flow 和声码器。
- 结合对齐路径、音素时长分布与 prior decoder 输出，定位并修复 MAS 对齐异常。
- 组织 PESQ、STOI、MCD、RTF 自动化评测。
- 使用外部噪声输入和固定随机种子，验证 PyTorch 与 ONNX 输出一致性。
- 开展 INT8 校准、验证和逐层敏感性分析。

不提供企业内部实现、语音、校准集、权重或算子适配资料。

## 诊断方法

以下是技术方法说明，不代表本仓库附有原始运行证据：

1. 对齐问题：联合观察音素时长、MAS 路径、异常停顿、重复或漏读，不只看总 loss。
2. 生成链路：先统一文本前处理、音素序列、推理长度及随机输入，再比较模型输出。
3. 导出检查：检查算子、输入输出 shape、动态长度和前后处理的一致性。
4. 量化分析：先固定浮点基线与校准方案，再逐层分析敏感性，并记录回退后的体积、延迟及质量。

## 三类验收必须分开

| 结论 | 所需证据 |
| --- | --- |
| 可以导出 | 导出脚本、模型检查和算子清单 |
| 数值一致 | 同输入、同噪声、同长度下逐样本误差及失败样例 |
| 目标设备可部署 | 实机执行、支持算子、端到端时延、峰值内存、模型体积及质量验收 |

ONNX 在桌面运行不代表目标 NPU 通过；模型参数量也不能单独证明部署文件满足体积约束。
