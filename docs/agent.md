# TeleAI：Agent 数据与执行评测

## 职责与边界

2026.03–2026.05，中国电信人工智能研究院基础模型组实习。根据现有简历，个人工作包括：

- 构造文件、办公、数据库、日程、地图及定时任务的工具调用 Query，引入画像、时间、路径、Skill / Cron 等约束，组织 L1/L2/L3 难度。
- 参与文件操作评测样本建设、目录映射、跨源元数据与一致性校验。
- 基于 OpenClaw / TeleGym 执行任务，分析工具调用轨迹、任务状态、落盘结果和最终回复，编写日志聚合脚本。
- 针对异步任务处理重试、延迟观测与执行报告。

不把数据与评测工作写成已经完成基础模型训练。简历中的样本规模及任务成功率没有在本仓库提供原始证据，因此不作为公开可复现指标。

## 通用工程方法

下列是可公开讨论的设计说明，不是内部实现或运行记录。

1. **任务契约**：输入资源、可用工具、初始状态、预期产物、截止条件、禁止副作用。
2. **轨迹解析**：保留调用序号、工具名、参数校验、返回状态及错误类型。
3. **产物验证**：文件存在不等于内容正确；检查 schema、行数、字段、预期变更和未授权改动。
4. **异步观测**：区分已调度、运行中、已完成、超时；设置固定观察窗和重试预算。
5. **最终回复**：核对回复描述与真实产物，避免“声称完成但未落盘”。

## 待执行的独立评测设计

仅使用自行编写的合成任务和公开许可文件重建独立环境，不复制内部数据或轨迹。

- 同一基础任务及变体按 base_task_id 分组隔离；需要时进一步隔离模板或工具族。
- 固定 executor、模型 revision、工具版本、最大步数和观察窗。
- 分开统计工具调用格式、任务完成、产物正确、最终回复一致性；同时报告独立任务数、轨迹数和变体数。
- 比较有无重试与延迟观测时，报告额外成本；不将系统观测变化写成模型能力提升。
- 若后续训练，额外保存梯度、权重差异与 reload 检查；能力提升必须经隔离集上的固定协议检验。
- 报告失败类型：参数错误、路径或时间误解、工具异常、状态判断错误、产物错误及虚假完成。

本仓库没有内部数据、评测集、执行器实现或训练权重。上述公开独立实验尚未执行。
