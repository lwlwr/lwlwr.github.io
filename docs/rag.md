## 待执行的独立评测方案

用自建或公开许可文档独立实现，不复制企业项目。

- 按来源文档、模板或时间隔离后再切块，防止同源 chunk 泄漏。
- 固定问题集，包含可回答、证据不足、领域外及提示注入问题。
- 分开报告检索 Recall@K、答案正确性、引用支持度和拒答 precision / recall / F1；每项保留分母及标注标准。
- 对 chunk size、Top-K、阈值、Prompt、是否微调分别消融，保持模型与测试集一致。
- 失败样例标注为检索失败、证据歧义、错误引用、无证据强答或错误拒答。
- 如验证 SFT，保存数据来源、训练配置、checkpoint 和更新证据，使用固定独立测试集比较。
